DPPCC ICC-STYLE WEBSITE PACKAGE

এই প্যাকেজে Home, Players, Men’s Rankings, Fixtures & Results, Match Centre, News, Videos, Gallery, Awards, About, Player Registration, Jersey Order, Contact, Staff Login এবং Owner/Admin/Manager/Captain Dashboard-এর পেজ রয়েছে।

গুরুত্বপূর্ণ:
1. আগের assets/dppcc-club-logo.jpg এবং assets/dppcc-sponsor-2003.jpg ফাইল এই assets ফোল্ডারে কপি করুন।
2. খেলোয়াড়ের ছবি images/players/player-1.jpg, player-2.jpg ইত্যাদি নামে রাখুন।
3. assets/hero-cricket.jpg, news-placeholder.jpg, match-placeholder.jpg আপনার ক্লাবের ছবি দিয়ে যোগ করুন।
4. firebase-config.js-এ Firebase Console থেকে সঠিক apiKey, appId ও storageBucket বসাতে হবে।
5. ফর্ম, login এবং dashboard এখন ডিজাইন/ইন্টারফেস। Firebase Authentication, Firestore, Storage ও Security Rules configure/deploy না করা পর্যন্ত এগুলো বাস্তব ডেটা জমা বা নিরাপদ staff login করবে না।
6. firebase.rules.txt হলো starter rules; deploy করার আগে role permission পরীক্ষা করুন।
7. কোনো খেলোয়াড়, খবর, স্কোর বা পুরস্কারের ভুয়া তথ্য দেওয়া হয়নি।
8. GitHub Pages repository root-এ সব ফাইল আপলোড করুন; আগের assets ও images ফোল্ডার অক্ষত রাখুন।
